# CBC Firepower Components Ponder 教程需求

## 1. 目标

为模组中需要玩家理解摆放方向、组装关系、弹药流向或交互方式的内容补充 Create Ponder（“俺寻思”）教程。

教程应回答三个问题：

1. 这个方块或物品是做什么的；
2. 应该怎样摆放、连接和操作；
3. 在 CBC、CBCMS、CBCAT、CBCMW/CBCNW 与可选线控模组共同安装时，哪些连接方式有效。

## 2. 版本范围

### 2.1 NeoForge 1.21.1

提供完整教程，覆盖当前 0.3.5 的全部核心玩法系统。

### 2.2 Forge 1.20.1

为该版本实际存在的功能提供基础教程：

- 紧凑型火炮炮座；
- 紧凑型机炮炮座；
- 机炮供弹器；
- 大型机炮弹药箱；
- 火炮弹匣装填器；
- 火炮限制器；
- 套筒式机枪盾。

不把 1.21.1 独有方块反向移植到 1.20.1。

## 3. 场景分组

### 3.1 紧凑型炮座

用一组场景说明：

- 紧凑型火炮炮座和紧凑型机炮炮座的用途；
- 炮体、炮座与动力输入的正确相对位置；
- 竖向紧凑型火炮炮座支持向上或向下安装；
- 竖向炮座的横向连接杆、两侧支架和组装方向；
- 炮座可承载兼容模组的受支持炮体，但不在教程中硬编码未安装模组的方块。

### 3.2 大型机炮

用单管和双联两个场景说明：

- 炮闩、炮管、细炮管和制退器的组装顺序；
- 弹药箱、供弹器和炮闩之间的弹药流向；
- 普通弹与高爆弹均可使用；
- 双联大型机炮交替开火；
- 炮弹从对应炮管口生成；
- 炮管开火时复进，安装制退器后后坐行程和实际后坐力降低。

### 3.3 火炮弹匣装填器

说明弹头与发射药的输入顺序、完整发射弹的形成，以及装填器向火炮提供弹药的用途。

### 3.4 智能待发弹药舱

说明：

- 每个仓位只保存一套完整发射弹；
- 弹头和发射药应按一套弹药配对；
- 输入按队列顺延，不从首格反复开始；
- 空出的前方仓位会自动进位；
- 玩家可在 GUI 中手动调整弹种顺序；
- 可由机械臂、漏斗等物流设备输入和输出；
- 输出口可直接向受支持的炮座供弹，不要求中间存在三发火炮弹匣；
- 可识别本模组、CBC 及已适配的 CBCMS、CBCAT、CBCMW/CBCNW 弹药。

### 3.5 转盘式待发弹药架

说明：

- 3×3 占地、24 个单发仓位和中央机构；
- 弹药在转盘内水平躺放；
- 靠近炮座的一侧形成输出口；
- 输出口前的弹药被取走后，转盘自动向前进位；
- 玩家可用 GUI 调整队列，也可空手取回弹药；
- 机械臂及兼容物流可从输出端取出弹药；
- Shift 查看详情只显示结构与容量信息，不在普通状态持续显示大段说明。

### 3.6 空药筒回收器

说明：

- 回收器在范围内收集受支持的空弹壳或空药筒；
- 从筒口上方可直接观察“空、部分装填、接近装满”的真实弹壳堆积；
- 状态由筒内堆积高度表达，而不是状态灯或固定数量的装饰弹壳；
- 机械臂和其他物流设备可从回收器取出回收物。

### 3.7 自动火炮控制器

说明：

- 短按右键触发一次开火；
- 按住右键打开 Create 风格的切换式 GUI；
- GUI 可选择单发、三发点射、连续射击，以及轮询或齐射调度；
- 潜行右键切换待发弹种；
- 背面红石上升沿等价于一次短按右键；
- 控制器可同时控制已绑定的炮座与智能待发弹药设备；
- 轮询会在可用炮座间逐次前进，齐射会同时触发；
- 连续射击和三发点射保留目标机炮自身可用的射速，不人为限制为低射速；
- 普通红石控制始终可用；
- Drive By Wire 仅作为可选的虚空连线升级方式，不替代红石逻辑。

### 3.8 火炮限制器与机枪盾

用简短场景说明限制器的作用方式。套筒式机枪盾只在实际注册该条目的 1.20.1 版本说明正确安装位置。纯外观内容不拆成多个重复场景。

### 3.9 望远镜测距

在望远镜条目上提供简短教程，说明：

- 使用绑定按键进行测距；
- 只返回视线最近碰撞点的实际直线距离；
- 不识别、锁定或保存目标；
- 在航空学物理体之间测量时使用实际世界空间距离，避免把物理体局部坐标直接相减。

## 4. 表现要求

1. 所有教程使用 Create/Ponder 原生界面与视觉语言。
2. 场景文本同时提供简体中文和英文。
3. 关键方向必须用箭头、框选、旋转视角或输入输出提示表现，不能只靠文字描述。
4. 弹药流动、转盘进位、炮管复进、回收器堆积和控制器调度必须有可见动画。
5. 场景应按功能分段，可快进或回退，不使用过长的单段演示。
6. 教程中引用可选模组时，未安装该模组不得导致注册失败、资源缺失或游戏崩溃。
7. 教程不得创建与实际实现不一致的“演示专用规则”。

## 5. 验收标准

1. 当玩家在 1.21.1 对任一核心功能条目打开 Ponder 时，系统应至少提供一个与该条目相关的教程场景。
2. 当玩家在 1.20.1 对该版本已存在的七项功能打开 Ponder 时，系统应提供对应基础场景。
3. 当语言为 `zh_cn` 或 `en_us` 时，所有新增教程标题、章节和说明都应有对应翻译，不应显示翻译键。
4. 当 CBCMS、CBCAT、CBCMW/CBCNW 或 Drive By Wire 未安装时，Ponder 注册和播放仍应正常工作。
5. 当场景演示弹药移动时，显示顺序应与真实队列、输出口和自动进位逻辑一致。
6. 当场景演示控制器时，红石上升沿、短按、模式切换、轮询、齐射和射速表现应与实际逻辑一致。
7. 当场景演示回收器时，玩家应能从筒口上方辨认空、部分装填和接近装满三类状态。
8. 两个版本均应通过各自的编译与资源检查；1.21.1 测试 JAR 应复制到指定测试实例。

## 6. 非目标

- 不为每个仅有材质差异的炮管零件制作独立重复教程；
- 不在 Ponder 中实现新的功能逻辑；
- 不要求安装任何兼容模组才能查看本模组教程；
- 不在本次工作中把 1.21.1 的智能弹药、回收器、控制器或转盘系统移植到 1.20.1。
