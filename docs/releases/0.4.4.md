# CBC: Firepower Components 0.4.4 — NeoForge 1.21.1

## 中文

- 包含 0.4.3 的 Radar 5.0 EA 3.1.3 公共炮座、武器与弹道 API 适配，以及独立的 Radar 0.4.9.4 兼容路径。
- 修复 EA 3 数据链自动选敌后，紧凑炮座火控仍使用首次锁定位置的问题。现在从 Radar 公共网络 API 同步已选目标，并对最近一次扫描的有限延迟进行速度补偿。
- 修复拆除数据链后残留的自动开火指令。保留望远镜控制和未联网炮座的原有行为。
- 补充实际雷达扫描、数据链物品连接、过滤器配置、自动选敌、真实弹丸碰撞命中和断链停火的服务器集成测试。
- 仅更新 NeoForge 1.21.1；Forge 1.20.1 版本不变。

## English

- Includes 0.4.3's Radar 5.0 EA 3.1.3 public mount, weapon, and shot API integration, plus the isolated Radar 0.4.9.4 compatibility path.
- Fixes compact mounts firing at the initial acquisition position after data-link auto-selection. Refreshes the selected contact through Radar's public network API and compensates for bounded recent scan latency.
- Clears a cached automatic firing command when its data link is removed. Preserves binocular and standalone control.
- Adds server integration coverage for native radar scanning, data-link item interactions, filter configuration, automatic selection, real projectile impacts, and stopping after unlinking.
- NeoForge 1.21.1 only; Forge 1.20.1 is unchanged.

Requires Create 6.0.x, Create Big Cannons 5.11.7 and Ritchie's Projectile Library 2.1.2. Radar and Sable remain optional.
See `docs/radar-ea313-validation.md` for the tested scenarios and limitations. These tests do not establish a general hit rate or coverage of every moving ship or modpack.
