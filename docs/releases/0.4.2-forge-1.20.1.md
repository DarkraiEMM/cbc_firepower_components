# CBC: Firepower Components 0.4.2 — Forge 1.20.1

## 中文

### 适用版本

| 项目 | 版本与边界 |
| --- | --- |
| Minecraft | 1.20.1 |
| Forge | 47.x（开发与构建基线 47.2.32） |
| Create | 6.0.8-289 |
| Create Big Cannons | 5.11.4 |
| Ritchie's Projectile Library | 2.1.1 |
| Create: Radar | 可选；0.4.6 发行文件，模组内部版本为 0.4.5 |

### 更新内容

- 将 Forge 1.20.1 独立维护线从 0.3.2 升级到 0.4.2。
- 移植自动火炮控制器、竖直紧凑型炮座、轮盘待发弹药舱、智能待发弹药舱和弹壳收集器。
- 移植单管与双管大型自动炮、弹药、炮尾状态模型及相关渲染修复。
- 同步统一后的控制器、限位器和弹药舱 GUI，并针对 1.20.1 调整交互与物品存储。
- 炮弹装填机现在支持 CBC 固定式炮座，并修复完整与不完整弹药组并存时可能停止工作的情况。
- 机械臂可识别待发弹药舱、轮盘弹药架、弹壳收集器和竖直紧凑型炮座。
- 同步弹种选择、固定炮座自动控制、竖直炮座退出操控崩溃和大型自动炮模型/UV 修复。
- 修复部分整合环境中加载大型自动炮弹药箱时可能导致游戏无法启动的问题，并提高 Radar 数据链接物品的交互兼容性。

### Create: Radar 兼容边界

- 使用 `create_radar-0.4.6+mc1.20.1.jar` 完成兼容测试；游戏内可能将其显示为 0.4.5。
- Radar 可以与本模组共同启动，数据链接以及水平、俯仰控制器均可识别紧凑型炮座。
- 兼容层支持选择紧凑型炮座，并为旧版 Radar 控制器提供水平与俯仰目标适配。
- 受该旧版 Radar 自身功能边界影响，本版本不承诺紧凑型炮座可以由 Radar 完成全自动开火。
- Radar 5.0、Sable 和 Vestalihy 属于 1.21.1 兼容线，不加入 Forge 1.20.1 构建。

### 其他附属

- 保留对可与 CBC 5.11.4 共存的 CBC Modern Warfare 版本的可选支持；它不是必需依赖，请注意不同版本之间可能不兼容。
- CBC Military Supplement/CBC More Shells 仅支持较旧的 CBC 版本，与本构建要求的 CBC 5.11.4 不兼容，因此不包含其依赖、专用装填器或炮座数据。
- 没有拿到对应 1.20.1 实际模组包并完成游戏内验证的附属，不列为完整兼容。

### 测试情况

- Forge 1.20.1 基础组合完成客户端主菜单启动。
- 加入实际 Radar 0.4.6 文件后，再次完成客户端主菜单启动。
- 修正后的正式包已在实际整合环境中完成后续测试，原启动问题暂未再次出现。
- 其他玩法与附属兼容仍会继续观察；若遇到问题，请附上游戏日志和完整模组列表。

### Changes

- Updated the independently maintained Forge 1.20.1 line from 0.3.2 to 0.4.2.
- Backported the Automatic Cannon Controller, Vertical Compact Cannon Mount, Carousel Ready Rack, Ready Ammunition Compartment, and Spent Casing Collector.
- Backported the single- and twin-barrel large-autocannon families, ammunition, breech-state models, and related rendering fixes.
- Synchronized the unified controller, limiter, and ammunition-container GUIs, with interaction and item storage adjusted for Minecraft 1.20.1.
- Added CBC fixed-mount support to the Cannon Magazine Loader and fixed stalls when complete and incomplete ammunition groups are present together.
- Added Mechanical Arm interaction for the ready compartment, carousel, spent-casing collector, and vertical compact mount.
- Synchronized ammunition selection, fixed-mount automatic control, vertical-mount dismount crash, and large-autocannon model/UV fixes.
- Fixed a startup failure that could occur while loading the Large Autocannon Ammo Box in some modpack environments, and improved Radar data-link interaction compatibility.

### Create: Radar compatibility boundary

- Tested against `create_radar-0.4.6+mc1.20.1.jar`; the in-game mod list may display it as version 0.4.5.
- Radar and Firepower Components start together, and the data link plus yaw and pitch controllers can recognize compact mounts.
- The compatibility layer lets the data link select compact mounts and adapts legacy Radar yaw and pitch targets.
- Because of limitations in this older Radar release, full Radar-controlled automatic firing for compact mounts is not guaranteed.
- Radar 5.0, Sable, and Vestalihy belong to the 1.21.1 compatibility line and are not included in the Forge 1.20.1 build.

### Other addons

- Optional support remains for CBC Modern Warfare builds that can coexist with CBC 5.11.4. It is not required, and some version combinations may be incompatible.
- CBC Military Supplement/CBC More Shells targets older CBC releases and cannot coexist with this build's required CBC 5.11.4, so its dependency, dedicated loaders, and mount data are excluded.
- Addons without an actual 1.20.1 artifact and in-game validation are not listed as fully compatible.

### Testing status

- The base Forge 1.20.1 stack reached the client main menu.
- The client reached the main menu again with the actual Radar 0.4.6 file installed.
- Follow-up testing of the corrected release in an actual modpack environment has not reproduced the original startup problem.
- Broader gameplay and addon compatibility remain under observation. If you encounter a problem, please include the game log and complete mod list in your report.
