# CBC: Firepower Components 0.4.0

## 中文

### 适用版本

- **主版本：** Minecraft 1.21.1 / NeoForge，Create 6.0.x，Create Big Cannons 5.11.7。
- **兼容维护版：** Minecraft 1.20.1 / Forge `0.3.2`，Create 6.0.8，Create Big Cannons 5.11.4。
- Forge 1.20.1 是独立维护线，不包含 NeoForge 0.4.0 的全部新功能。

### 界面重构

- 统一重构转盘式待发弹药架、智能待发弹舱、自动火炮控制器和火炮限位器 GUI，采用机械动力风格与军用仪表配色。
- 缩小并重新排布界面，修复低分辨率下超出屏幕的问题。
- 修复自动火炮控制器无法正常打开的问题；空手或手持物品右键均可进入配置界面。
- 将手动开火操作移入控制器 GUI，避免与打开界面的交互冲突。
- 压缩护目镜信息为两行状态摘要，避免图标遮挡文字。

### 模型、贴图与 UV

- 重制转盘式待发弹药架和智能待发弹舱的模型、物品栏显示、材质分区及内部弹药显示结构。
- 重制空药筒回收器的空、半满、满载状态及物品模型，提高药筒堆的辨识度。
- 调整竖直紧凑型炮座的侧板、支撑结构和高度比例，使横杆在上一格位置显示并生效。
- 修正大型机炮炮管、炮尾、推拉栓和制退器的模型朝向、碰撞范围及 UV 重叠问题。
- 清理多处重复表面和贴图堆叠，减少闪烁、黑面与紫黑缺失贴图。

### 功能与兼容性修复

- 火炮限位器现在可安装到 CBC 原版普通炮座，同时保留紧凑型炮座的角度限制、保存和拆卸功能。
- 紧凑型炮座下车时会检查附近空间与地面，优先选择安全落点。
- 弹匣装弹机现在可识别 CBC 固定炮座。
- 修复同时存在完整弹组和残缺弹组时，装弹流程可能永久锁死的问题。
- 保留弹头、发射药和引信的顺序装填逻辑，并继续通过 CBC 标准接口兼容可接入该接口的附属弹药。
- 增加 Vestalihy 对本模组紧凑型炮座的可选识别支持。
- 保留 CBC Neo Warfare 等附属通过 CBC 炮座输入接口进行装弹的兼容路径。

### 已验证

- NeoForge 1.21.1 与 CBC 5.11.7 可完成构建并启动服务端。
- Vestalihy 2.5.3 与 Sable 2.0.5 的组合可完成服务端启动。
- Forge 1.20.1 / Create 6.0.8 / CBC 5.11.4 已通过构建与模组加载阶段验证。

## English

### Supported versions

- **Main release:** Minecraft 1.21.1 / NeoForge, Create 6.0.x, and Create Big Cannons 5.11.7.
- **Maintenance build:** Minecraft 1.20.1 / Forge `0.3.2`, Create 6.0.8, and Create Big Cannons 5.11.4.
- The Forge 1.20.1 build is maintained separately and does not include every NeoForge 0.4.0 feature.

### Interface rebuild

- Rebuilt the Carousel Ready Rack, Ready Ammunition Compartment, Automatic Cannon Controller, and Cannon Limiter screens around one compact Create-inspired military interface.
- Reduced and rearranged screen layouts so they remain usable at lower GUI resolutions.
- Fixed the Automatic Cannon Controller configuration screen not opening reliably. It now opens whether the player is empty-handed or holding an item.
- Moved manual firing into the controller screen to avoid conflicts with the interaction used to open it.
- Condensed controller goggle information into two status lines so the icon no longer covers the text.

### Models, textures, and UVs

- Rebuilt the Carousel Ready Rack and Ready Ammunition Compartment models, inventory displays, material regions, and internal ammunition presentation.
- Reworked the empty, half-full, and full Spent Casing Collector states and its inventory model for clearer casing piles.
- Compressed the Vertical Compact Cannon Mount side panels, supports, and proportions so its trunnion operates one block above the base.
- Corrected large-autocannon barrel, breech, sliding-block, and muzzle-brake orientation, collision, and overlapping UV issues.
- Removed multiple duplicate faces and stacked texture regions that caused flicker, black surfaces, or missing-texture rendering.

### Gameplay and compatibility fixes

- The Cannon Limiter can now be installed on normal CBC cannon mounts while retaining compact-mount angle limits, persistence, and removal.
- Compact mounts now check nearby clearance and floor support when choosing a dismount position.
- The Cannon Magazine Loader now recognizes CBC fixed cannon mounts.
- Fixed a loader deadlock when complete and incomplete ammunition groups were stored at the same time.
- Retained ordered projectile, propellant, and fuze insertion and the standard CBC ammunition-input bridge used by compatible addons.
- Added optional Vestalihy recognition for this mod's compact cannon mount.
- Retained the CBC mount-input compatibility path used by addons such as CBC Neo Warfare.

### Validation

- The NeoForge 1.21.1 build completed and reached a successful dedicated-server startup with CBC 5.11.7.
- A Vestalihy 2.5.3 and Sable 2.0.5 compatibility stack also reached a successful dedicated-server startup.
- The Forge 1.20.1 / Create 6.0.8 / CBC 5.11.4 line passed the build and mod-loading stages.
