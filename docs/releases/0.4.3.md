# CBC: Firepower Components 0.4.3 — NeoForge 1.21.1

## 中文

- 适配 Create: Radar **5.0 EA 3.1.3**，优先使用公开炮座、武器与弹道 API；保留 Radar **0.4.9.4** 的独立兼容路径。
- 修正 EA 3 公共 API 路径中 Sable 船体的世界方向与炮座本地方向转换，支持带有俯仰、横滚和转向的船体。弹道继承船体速度时遵循 CBC 的配置开关。
- 按实际装填弹药提供弹速、重力、阻力、寿命和炮口位置；空仓或不支持的弹药不再被当作可直接射击的武器。
- 补全 Radar 4.9 的紧凑炮座自动开火接入，保留 Radar 原生的目标、弹道与开火判定；修复空仓、目标失效、开火控制器拆除和数据链断开后的自动输出清理。
- 本次只更新 NeoForge 1.21.1。依赖 Create 6.0.x、Create Big Cannons 5.11.7、Ritchie's Projectile Library 2.1.2；移动船体验证使用 Sable 2.0.3。

## English

- Integrates Create: Radar **5.0 EA 3.1.3** through its public mount, weapon, and shot APIs, while retaining a separate **0.4.9.4** compatibility path.
- Corrects EA 3 world/local aiming on translating, turning, and tilted Sable ships. Projectile velocity inheritance follows CBC's configuration.
- Resolves ballistics and muzzle position from the loaded ammunition. Empty or unsupported weapons no longer advertise a ready direct-fire shot.
- Completes compact-mount automatic firing on Radar 4.9 while preserving Radar's native targeting and firing decisions. Clears automatic output on empty ammunition, invalid targets, removed fire controllers, and disconnected data links.
- This update targets NeoForge 1.21.1 with Create 6.0.x, Create Big Cannons 5.11.7, and Ritchie's Projectile Library 2.1.2. Moving-ship validation uses Sable 2.0.3. The Forge 1.20.1 line is unchanged.

Validation details and limitations are recorded in `docs/radar-ea313-validation.md` in the source repository.
